# Effective Agents — Brand

**Primary tagline:** Ship Outcomes, Not Chat

---

## Name

**Effective Agents**

Short form: *EA* (internal only). Prefer the full name in public copy.

Avoid: “EffectiveAI”, “EA Agents”, “Agent Effective”. Do not stylise as all-caps except in logo lockups.

---

## One-liner

Intelligence that works inside the tools people already use — agents composed, governed, measurable, and improved by human feedback on Microsoft’s agent stack.

---

## Positioning

Effective Agents helps Microsoft-centric organisations turn Copilot, SharePoint, Copilot Studio, Agent Builder, and Microsoft Foundry into **outcome-shipping agents** — not chatbots bolted onto the intranet.

We reclaim **RLHF** (reinforcement learning from human feedback) as the enterprise feedback loop: preference signals from real work in Microsoft 365 train and steer agents that complete tasks, escalate when unsure, and get better every week.

We are **not** affiliated with Microsoft or with TypeSafe AI. We build on Microsoft technologies and share a manifesto-grade seriousness about production intelligence — with a different thesis: chat is fine as a surface; **effectiveness** is the product.

| Dimension | Effective Agents |
|-----------|------------------|
| Surface | Microsoft 365, SharePoint, Teams, Copilot |
| Unit of value | Completed outcome (file updated, approval routed, case closed) |
| Feedback | Human preference loops grounded in real work |
| Risk posture | Governed emergence via Purview, Foundry, Scout, eval sets |
| Buyer promise | Agents you can measure, audit, and improve |

## Voice

**Tone:** Editorial, direct, slightly industrial. Short sentences. Concrete nouns. Prefer “ships”, “grounds”, “escalates”, “measures” over “empowers”, “revolutionises”, “unlocks”.

**Spelling:** en-GB (organisation, behaviour, modelled, favourite).

**Do:**
- Name the Microsoft product when it matters (SharePoint agents, Copilot Studio, Foundry).
- Contrast *decorative chat* with *effective action*.
- Treat RLHF as a feature of enterprise maturity, not a research footnote.
- Use footnotes sparingly for definitions and product maps.

**Don’t:**
- Claim AGI, “digital employees”, or human replacement.
- Claim affiliation with Microsoft or TypeSafe.
- Soften governance into vibe (“trustworthy AI™”).
- Write like a generic Copilot partner brochure.

**Example lines:**
- “If it only answers, it isn’t an agent. If it finishes the job, it is.”
- “Preference without grounding is taste. Preference with Graph and SharePoint is training data.”
- “Chat theatre burns tokens. Effective agents burn cycle time.”

## Competitors & contrast

### vs TypeSafe (adjacent philosophy, different stack)
TypeSafe argues RLHF-trained chat models optimise for human-pleasing conversation and keep humans in the loop as a crutch. Effective Agents **reclaims** that loop: in the enterprise, human preference *is* the signal that steers agents toward outcomes inside Microsoft 365. We are not building a new model lab. We are building the practice, patterns, and product lines that make Microsoft’s agent stack **effective**.

### vs generic Copilot chat / “ask me anything” bots
Chat-on-your-docs is a horseless carriage: a familiar interface dragged onto enterprise knowledge. Useful for Q&A; insufficient for work that must be filed, approved, routed, or measured. We sell composition, grounding, action, feedback, and governance — not another prompt pack.

### vs pure custom LLM apps outside M365
Greenfield agent frameworks ignore where work already lives. Our bet: effectiveness compounds when agents sit in SharePoint, Teams, and Copilot — under the same identity, Purview, and audit plane the organisation already runs.

### vs “AI transformation” consultancies
We are concrete: named layers, named Microsoft products, named metrics. Advisory without a framework is theatre. Framework without shipped agents is slides.

## Brand pillars

1. **Inside the tools** — Agents live where work already happens (M365, SharePoint, Copilot).
2. **Composed, not monolithic** — Intent → Agent → Grounding → Action → Feedback → Governance.
3. **Grounded by default** — Graph, SharePoint, and permissions are the substrate, not an afterthought.
4. **RLHF as enterprise muscle** — Thumbs, corrections, escalations, and eval sets steer agents in production.
5. **Measurable effectiveness** — Task completion, time-to-outcome, escalation rate, confidence calibration.
6. **Governed emergence** — Scout, Foundry, Purview, and policy make scale safe enough to ship.
