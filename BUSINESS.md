# Effective Agents — Business Model Sketch

**Primary tagline:** Ship Outcomes, Not Chat

*Independent brand. Built on Microsoft technologies. Not affiliated with Microsoft or TypeSafe AI.*

## Who buys

| Buyer | Pain | What they fund |
|-------|------|----------------|
| **CIO / CTO** | Copilot licence spend without outcome proof | Estate framework + pilot → scale programme |
| **Copilot / AI CoE lead** | Pilot graveyard; inconsistent partner quality | Playbooks, patterns, enablement |
| **M365 / SharePoint platform owner** | Shadow agents; permission risk | Grounding standards + SharePoint agent builds |
| **Business unit sponsor** (HR, Legal, Finance Ops, Customer Ops) | Manual cycle time on repeatable work | Outcome-scoped agent build + HITL design |
| **CISO / Compliance** | Unauditable bots | Governance overlay (Purview, Foundry, Scout) |
| **Microsoft partner / SI** | Need a differentiated agent offer | White-label patterns + joint delivery |

**Ideal customer profile (ICP):** Microsoft 365 E3/E5-heavy organisation, 1,000–50,000 seats, existing Copilot or Copilot Studio investment, SharePoint as system of knowledge, appetite for measurable ROI within one quarter.

## Offers

### 1. Advisory — *Effective Agents Diagnostic*

**Duration:** 2–4 weeks  
**Output:** Agent opportunity map, risk heat-map, metric baseline, 90-day roadmap  
**Activities:** Stakeholder interviews, tenant/pattern review, decorative-vs-effective triage, governance gap analysis  
**Price posture:** Fixed fee

### 2. Build — *Outcome Agents*

Scoped delivery of one or more production agents on the Microsoft stack.

| Package | Scope | Typical outcomes |
|---------|-------|------------------|
| **Spark** | 1 agent, 1 intent, HITL, basic metrics | Prove completion rate vs baseline |
| **Line** | 3–5 agents, shared grounding standards, eval sets | Departmental cycle-time cut |
| **Estate** | Platform patterns + multiple BUs + Scout/Foundry overlay | CoE-operable agent factory |

Includes: Intent workshops, SharePoint/Graph grounding design, Copilot Studio / Agent Builder implementation, feedback instrumentation, dashboards, runbooks.

### 3. Platform patterns — *Effective Agents Kit*

Reusable IP licensed or delivered into the customer’s CoE:

- Layer templates (Intent → Governance)
- Preference-loop designs (thumbs, corrections, escalations)
- Eval-set starter packs by domain (HR, Legal, Finance Ops)
- Mermaid/reference architectures
- Metric definitions and Power BI / Excel board packs
- Do/don’t prompt and tool policies

### 4. Operate — *Effectiveness Retainer* (optional)

Monthly: eval gate reviews, preference sampling, version promotion, Scout/Purview check-ins, metric ops. For customers who want continuous improvement without standing up a full internal MLOps team.

## GTM for Microsoft-centric orgs

### Motion
1. **Land** with Diagnostic on a painful, measurable process (not “general Copilot adoption”).
2. **Expand** via Line builds in the same BU, then adjacent BUs sharing grounding standards.
3. **Embed** CoE with Platform patterns + Effectiveness Board.
4. **Ally** with Microsoft account teams and SIs as the “effectiveness” specialty — not competing with licence sales; converting licences into outcomes.

### Channels
- Direct to CIO / CoE
- Microsoft partner co-sell (position as delivery accelerators on Copilot Studio, Agent Builder, Foundry, SharePoint)
- Workshops / Our Goal landing (index.html) plus Insights, Choice, Measurements as top-of-funnel
- Case studies framed as **before/after metrics**, not feature tours

### Messaging hierarchy
1. Ship Outcomes, Not Chat  
2. Effective, Not Decorative  
3. RLHF as enterprise feedback — preference that ships  
4. Built on Microsoft technologies you already own  

### Proof points to collect early
- Task completion rate lift
- Median time-to-outcome vs manual baseline
- Escalation rate in a healthy band
- Zero critical Purview incidents in pilot window

### What not to sell
- “Custom GPT” islands outside M365 identity
- Unlimited chat bots per department
- Guarantees of full autonomy without HITL on high-risk actions
- Affiliation claims with Microsoft or TypeSafe
