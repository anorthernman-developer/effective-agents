# Microsoft Copilot Studio: Cost visibility in Agent Evaluations

**Ship Outcomes, Not Chat** — a short read on a Microsoft 365 roadmap item.

## What it is

Microsoft Copilot Studio: Cost visibility in Agent Evaluations (Copilot Studio, Copilot, Agent). Roadmap id `571195`.

## What it does

<p>Now makers will have clear visibility into their consumption costs directly associated with their evaluations, including a breakdown of usage for eval generation, test runs and model grading/judgement. Makers can see the costs as they test, iterate, and review…

## What to worry about

Cost visibility without outcome metrics can become another chat bill. Tie spend to completed work.

## What it means for users

Makers and CoE leads get clearer levers on agent lifecycle cost and behaviour — use them to prove effectiveness, not just publish bots.
